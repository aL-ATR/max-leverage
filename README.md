# 梭哈计算器

一个纯前端、零依赖的 ATR 波动率杠杆计算器。根据 ATR 止损距离与用户设定的风险比例,反推出最多可用的杠杆倍数,并估算止损价格、名义持仓价值、持仓数量与预计亏损。

## 功能特性

- 支持 LONG(做多)/ SHORT(做空)双向计算
- 根据 ATR 与风险比例自动反推理论最大杠杆与实际可用杠杆
- 实时计算,无需点击按钮
- 完整的输入校验与错误提示
- 内置使用说明弹窗,含公式与示例
- 动态背景「电梯小人」:实际风险越高,小人所在楼层越高
- 响应式布局,适配桌面与手机

## 使用说明

1. 选择交易方向:LONG(做多)或 SHORT(做空)。
2. 填写入场价格与当前 K 线对应的 ATR 数值(ATR 需与价格使用相同计价单位)。
3. 设置 ATR 倍数、保证金、风险比例、交易所最大杠杆。
4. 左侧结果实时更新,无需点击计算按钮。
5. 按「实际可用杠杆」开仓,并把止损设在「止损价格」。

## 计算公式

```
止损距离     = ATR × ATR 倍数
理论最大杠杆 = (风险比例 × 入场价) ÷ 止损距离
实际可用杠杆 = min( 向下取整(理论杠杆), 交易所最大杠杆 )
止损价格     = 做多:入场价 − 止损距离
               做空:入场价 + 止损距离
名义持仓价值 = 保证金 × 实际杠杆
持仓数量     = 名义持仓价值 ÷ 入场价
预计亏损     = 名义持仓价值 × 止损距离 ÷ 入场价
```
