## 📖 简介

在合约交易中,杠杆倍数并不是越大越好——它应该由 **止损价格**(即止损离入场价的距离) 和 **你愿意承受的风险比例** 共同决定。本工具根据你的入场价、止损价格和风险偏好,反推出理论上最大的杠杆倍数,并进一步给出交易所规则下的实际可用杠杆与完整的持仓参数,帮助你「按风险开仓」而非「按情绪梭哈」。

**适用场景**:当你已经确定本次买入能够获得收益,想让这笔收益最大化时,就可以使用本系统——在设好止损、锁死风险的前提下,把可用杠杆拉满,梭哈专用。

**核心思想:**

```
止损距离     = abs( 入场价 − 止损价格 )
理论最大杠杆 = (风险比例 × 入场价) ÷ 止损距离
```

## 📋 使用说明

1. 选择**交易方向**:LONG(做多)或 SHORT(做空)。
2. 填写**入场价格**与**止损价格**(止损价格需与入场价同一计价单位)。
3. 设置**保证金**、**风险比例**、**交易所最大杠杆**。
4. 左侧结果**实时更新**,无需点击计算按钮。
5. 按「实际可用杠杆」开仓,并把止损设在「止损价格」。

### 参数说明

| 参数 | 说明 |
| :--- | :--- |
| 入场价格 (Entry Price) | 你的计划入场价 |
| 止损价格 (Stop-Loss Price) | 触发止损时的价格,决定止损距离 |
| 保证金 (Margin) | 计划投入的保证金,单位 USDT |
| 风险比例 (Risk Ratio) | 愿意承受的最大亏损占保证金比例,% |
| 交易所最大杠杆 | 交易平台允许的最高杠杆倍数 |

## 🧮 计算公式

| 项目 | 公式 |
| :--- | :--- |
| 止损距离 | `abs(入场价 − 止损价格)` |
| 理论最大杠杆 | `(风险比例 × 入场价) ÷ 止损距离` |
| 实际可用杠杆 | `min( 向下取整(理论杠杆), 交易所最大杠杆 )` |
| 止损价格 | 直接使用输入的止损价格 |
| 名义持仓价值 | `保证金 × 实际杠杆` |
| 持仓数量 | `名义持仓价值 ÷ 入场价` |
| 预计亏损 | `名义持仓价值 × 止损距离 ÷ 入场价` |
